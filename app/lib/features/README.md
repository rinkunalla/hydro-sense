# app/lib/features

* `auth/`: Login, Reset Password, Set a new password (both builds)
* `client/`: Devices, Device detail, Map, Account (Android build only)
* `admin/`: Overview, Devices, Create client, Hardware report, Errors (web build only)

Shared theme, config and data access live in `lib/core/`. Screens arrive in Phases 5 and 6.
